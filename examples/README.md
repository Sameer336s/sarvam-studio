# Examples

Things built with Sarvam Studio. Each folder is a self-contained project: open it, run it, no build step.

| Example | What it is | Live |
| --- | --- | --- |
| [`typefight/`](typefight/) | A one-file typing duel game — stickman combat, combos, rounds, Web Audio sound | [stickma.netlify.app](https://stickma.netlify.app) |

## Adding one

1. Save the generated output as a folder here (`examples/<name>/`).
2. Add a `README.md` with the prompt you used, what the model produced, and how to run it.
3. Add a row to the table above.

These are committed as they were produced — they are evidence of what the app can build, not a
maintained codebase. Fixes are welcome, but the point is the raw output.
